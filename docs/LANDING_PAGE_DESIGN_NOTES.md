# Landing-page design notes

This file preserves the internal alternatives previously carried in the public README. The shipped frontend, its tests, and current screenshots remain the evidence for what is implemented; these notes are design context, not a deployment or completion claim.

The detailed plan remains in [`../UNIVERSAL_LANDING_PAGE_PLAN.md`](../UNIVERSAL_LANDING_PAGE_PLAN.md).

## Explored alternatives

### Browser-Core Modernism

- Technical DevTools aesthetic
- High-contrast technical elements
- Browser chrome frame, tabs, and address bar
- Custom UI scrollbars and pattern-grid background
- JetBrains Mono for technical labels

### Bold Editorial Studio

- Typography-first black-and-white aesthetic
- Strong weight and size contrasts
- Asymmetrical rounded corners and smooth animations
- Mix-blend-mode cursor treatment

## Interaction goals

- Instant demo without signup
- Three-step “How it works” path
- Interactive citation trace
- Light and dark themes
- Mobile navigation
- Pre-populated demo questions
- Explicit loading states
- Hallucination challenge
