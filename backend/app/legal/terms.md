# What CiteVyn is

CiteVyn answers questions about the Claude API, Claude Code, Codex and Gemini from those products' official documentation, and cites the pages each answer comes from. When the documentation does not support an answer, CiteVyn says so instead of guessing.

# Answers can be wrong

Answers are written by an AI model from the cited pages. The model can misread or leave things out, and documentation changes. Check the cited page before you rely on an answer, especially for anything that costs money, touches security, or is hard to undo.
